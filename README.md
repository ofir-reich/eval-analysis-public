# Reanalysis of METR's Time Horizon data

This is a fork of [METR/eval-analysis-public](https://github.com/METR/eval-analysis-public) containing an independent reanalysis of the human-baseline side of METR's [time horizon methodology](https://arxiv.org/abs/2503.14499) ("Measuring AI Ability to Complete Long Tasks").

**The reanalysis lives in [`reanalysis/`](reanalysis/) — start with its [README](reanalysis/README.md).**

Everything outside `reanalysis/` is unmodified upstream code and data. For METR's own documentation of the pipeline, see the [original README](https://github.com/METR/eval-analysis-public#readme).
